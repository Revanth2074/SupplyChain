What you can do on every page

Eleven pages, grouped the way the sidebar is: Overview → Investigate → Predict & Decide → Act & Learn. Every input below has been run on the real app; press Copy, paste it into the page, press the button named in bold. Use the filter on the left to jump to a page or find a question.

⏱️ The 10-minute demo route

If you only have one go, do the pages in this order. Times are what each step really takes.

  1. 0:00Control Tower: let the 3D world run, press Port Congestion on the Simulate bar → sea lanes and ports turn red. Back to Normal operations.
  2. 0:45Control Tower: click Kansas Composite Works → Simulate a Cyber Attack here → the supervisor and the agents tick off in the side panel (~12 s).
  3. 2:00Incident Cockpit: Use sample incident → Analyse with agents. Point at the supervisor starting three agents in parallel, an agent's own steps and confidence, the Synapt playbook steps in the plan, "fact-check passed", the judge score.
  4. 3:30Same page: Run counterfactuals (what if we had a backup supplier) → then Open incident & track actions.
  5. 4:30Search & Ask: ask the port-congestion question → Synapt's own answer with confidence.
  6. 5:30Knowledge Graph: graph query → the reasoning subgraph Synapt walked; load the Cyber Attack playbook.
  7. 6:30Decision Studio: Compare options → recommended option and net benefit in money.
  8. 7:30Incident Desk: the incident you opened, SLA clock, escalation chain; tick an action done with an actual recovery.
  9. 8:15History: every step you just did is there; Open full analysis re-opens one without re-running.

🧯 If something goes wrong during the demo

Yellow banner "Loading 100,000 cases and models…"Normal for ~30 s after starting. Wait; every page reloads itself when the backend is ready. Banner shows a start-up errorThe app runs only on Synapt. If it is not configured or unreachable at boot, start-up stops at "error" and data pages return 503. Check SYNAPT_USERNAME / SYNAPT_PASSWORD / SYNAPT_PROVIDER_ID in backend/.env and the network, then restart the backend. Sidebar shows Synapt "error (tool)", "unreachable" or "not configured"A Synapt call failed. The request that hit it shows a clear error (HTTP 502, or an error in the Cockpit stream); /api/health names the last_failed_tool and last_error. Retry once Synapt answers again. Analysis takes 20–30 sSynapt graph-RAG is slow on the beta that day. Untick Synapt graph-RAG in the Cockpit for a ~3 s run (no graph answer). Judge LLM shows "not set" or evaluation falls back to the rule rubricThe judge key or model in backend/.env is missing, retired or out of credits. Set MODEL_NAME=nvidia/nemotron-3-super-120b-a12b. The workflow itself never needs it. 3D Control Tower says "unavailable"No internet for the three.js CDN. Every other page works; skip to the Incident Cockpit.
